# 三维模型来源

## acupuncture-bronze-human.glb

- 用途：人体经络与解剖页面的针灸经络铜人表面模型。
- 来源：`nirholas/three.ws` 项目的 `public/avatars/parametric-base.glb`。
- 上游模型：MakeHuman / MPFB2 `hm08` 参数化人体基础网格；运行时启用
  `bodyMasculine` 等 morph targets，生成偏男性的针灸铜人体型。
- 许可：CC0 1.0 Universal，可用于商业项目；本项目仅在运行时替换为古铜材质并叠加经络和穴位。
- 来源地址：https://github.com/nirholas/three.ws
- MakeHuman 许可：https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md

经络线、穴位点、交互和中文资料为本项目实现。模型及经穴位置均用于教学展示，不作为诊断、治疗或精确取穴依据。
